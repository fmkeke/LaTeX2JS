# 功能测试指南

## 📋 测试页面说明

### 1. 基础预览页面 (`index.html`)
- 简单的组件预览界面
- 支持手动输入 LaTeX 代码
- 适合快速测试单个组件

### 2. 完整功能测试页面 (`test-all.html`) ⭐
- **包含 12 个预设测试模板**
- 每个模板测试不同的功能
- 标签页切换，方便对比
- 自动加载示例代码

## 🧪 测试模板列表

### PSTricks 图形命令

1. **psframe - 矩形框**
   - 基本矩形框
   - 带选项的矩形框（linecolor, linewidth）
   - 多个矩形叠加

2. **pscircle - 圆形**
   - 基本圆形
   - 带边框和填充的圆形
   - 不同半径和样式

3. **psline - 直线**
   - 基本直线
   - 带箭头的直线（单向、双向）
   - 虚线、点线样式
   - 带点标记的直线

4. **pspolygon - 多边形**
   - 三角形
   - 四边形
   - 五边形
   - 填充和边框样式

5. **psarc - 圆弧**
   - 基本圆弧
   - 带箭头的圆弧
   - 不同角度范围
   - 半圆和完整圆

6. **psplot - 函数图像**
   - 二次函数 y = x²
   - 正弦函数 y = sin(x)
   - 线性函数 y = x
   - 代数函数绘制

7. **psaxes - 坐标轴**
   - 基本坐标轴
   - 带刻度的坐标轴
   - 不显示原点的坐标轴
   - 自定义刻度间距

8. **rput - 文本放置**
   - 基本文本
   - 数学公式标签
   - 不同位置放置

### 组合和高级功能

9. **组合示例 - 完整图形**
   - 多个命令组合使用
   - 函数图像 + 标记点 + 连接线
   - 完整的数学图形示例

10. **数学公式**
    - 行内公式
    - 块级公式
    - 复杂公式（积分、矩阵等）

11. **文本格式化**
    - 粗体、斜体、强调
    - 链接
    - 混合格式

12. **环境测试**
    - enumerate（列表）
    - verbatim（代码块）
    - nicebox（带标题的框）

## 🚀 使用方法

### 启动开发服务器

```bash
pnpm dev
```

### 访问测试页面

1. **基础预览**: http://localhost:3000/
2. **完整功能测试**: http://localhost:3000/test-all.html

### 测试步骤

1. 打开 `test-all.html` 页面
2. 点击顶部的标签页选择测试模板
3. 查看左侧的代码和描述
4. 点击"渲染"按钮查看效果
5. 可以修改代码后重新渲染
6. 切换不同模板对比效果
