# LaTeX2JS 组件预览开发环境

## 🚀 快速开始

### 1. 启动开发服务器

```bash
pnpm dev
```

开发服务器会在 `http://localhost:3000` 启动，并自动打开浏览器。

### 2. 使用预览界面

#### 基础预览页面 (`index.html`)
- **选择组件**: 从下拉菜单中选择要预览的组件类型
- **编辑代码**: 在文本框中输入或修改 LaTeX 代码
- **渲染**: 点击"渲染"按钮查看效果
- **清空**: 点击"清空"按钮清空预览区域

#### 完整功能测试页面 (`test-all.html`) ⭐ **推荐**
- **12 个预设测试模板**: 点击顶部标签页切换
- **自动加载代码**: 选择模板后自动加载示例代码
- **双栏布局**: 左侧代码，右侧预览
- **状态显示**: 实时显示渲染状态

访问地址：
- 基础预览: http://localhost:3000/
- 完整测试: http://localhost:3000/test-all.html

## 📦 支持的组件

- **Math**: 数学公式（行内和块级）
- **PSTricks Picture**: PSTricks 图形
- **Nicebox**: 带标题的框（如定理框）
- **Enumerate**: 有序列表
- **Verbatim**: 代码块
- **Custom**: 自定义混合内容

## 🧪 测试模板（test-all.html）

### PSTricks 图形命令
1. **psframe** - 矩形框测试
2. **pscircle** - 圆形测试
3. **psline** - 直线测试（箭头、虚线、点线）
4. **pspolygon** - 多边形测试
5. **psarc** - 圆弧测试
6. **psplot** - 函数图像测试
7. **psaxes** - 坐标轴测试
8. **rput** - 文本放置测试

### 组合和高级功能
9. **组合示例** - 完整图形示例
10. **数学公式** - 各种数学公式
11. **文本格式化** - 文本样式
12. **环境测试** - enumerate、verbatim、nicebox

详细说明请查看 [TEST_GUIDE.md](./TEST_GUIDE.md)

## 🔥 热更新

修改源代码后，Vite 会自动：
- 重新编译 TypeScript
- 刷新浏览器页面
- 保持当前预览状态（如果可能）

## 🛠️ 开发技巧

1. **实时预览**: 修改组件代码后，刷新页面即可看到最新效果
2. **组件切换**: 使用下拉菜单快速切换不同组件的示例
3. **自定义测试**: 选择"Custom"选项，输入自己的 LaTeX 代码进行测试
4. **模板测试**: 使用 `test-all.html` 快速测试所有功能

## ⚙️ 配置

Vite 配置文件位于根目录的 `vite.config.ts`，可以修改：
- 端口号（默认 3000）
- 路径别名
- 其他 Vite 选项
